# v1.11.0-beta.3 — GitHub update test

A version-only pre-release for testing an update from **beta.2 through the
clock's web interface**. It includes no new features or bug fixes.

## Changed

- Firmware version: **1.11.0-beta.2 → 1.11.0-beta.3**.
- All other firmware code and embedded web assets are unchanged. Existing
  settings, screen selections and the maintenance PIN remain compatible.

## Test the update

On a clock already running beta.2:

1. Open `/update` and select **Stable + Beta**.
2. Press **Check GitHub**. The page should offer **1.11.0-beta.3**.
3. Show the PIN on the clock, enter its six digits, and press **Install & restart**.
4. Keep the browser tab open while it downloads, verifies and uploads the image.
5. After the clock restarts, reload the page and confirm **1.11.0-beta.3** is
   reported and your settings/screens are retained.
6. Check GitHub again: the page should report that no newer release is available.

The **Stable** channel continues to offer 1.10.0 and does not install a downgrade.
There is no unattended update schedule or automatic rollback. GitHub caching can
briefly delay discovery immediately after publication; retry the check if needed.
If the installed firmware is older than beta.2, use the existing manual upload
first. Manual installation needs only the `.bin` in **Firmware**; leave
**FileSystem** empty.

## Validation and scope

Release assets come from the pinned GitHub Actions build. The build and existing
regression suites check the firmware, browser flow, version ordering, image
integrity and memory budgets. Only the binary, `SHA256SUMS` and `BUILD_INFO.txt`
are attached; the release description links to its exact build result.

**Physical OTA, reboot/recovery and long-running hardware validation remain
pending.** This pre-release provides the next version for that test; publication
does not mean the clock has already been updated.
