# v1.11.0 — more weather, GitHub updates and four languages

**2026-11-03**. Stable release of the 1.11 line. Changes are relative to the previous
stable release, **v1.10.0**; everything from the four 1.11.0 pre-releases is included.
Settings, maintenance PIN and the EEPROM layout are unchanged from 1.10.0 and from
every 1.11 beta, so updating keeps your configuration.

## What's new since 1.10.0

- **Web interface in English, Italiano, Deutsch and Français.** Pick the language
  at the top of Settings and save; it applies at once on every page and in every
  browser, because the clock stores the choice. Dates on the Clock page follow the
  language. Your browser downloads the dictionary from this repository: the 1 MB
  flash has no room for it, so without internet access the page stays in English
  and says so. The OLED itself is not translated.
- **More weather on the OLED, all opt-in.** Combined time-and-weather page, outdoor
  comfort (feels-like, humidity), hourly rain probability, two-day min/max, a
  daytime UV peak page with today's level and tomorrow's maximum, wind direction,
  a moon at night and a countdown to the next sun event. Screen presets, per-page
  durations, hold/next/direct screen selection, °C/°F and km/h, m/s, mph.
- **Night mode can dim** to a separate brightness instead of turning the OLED off.
- **Home Assistant cards.** One opt-in external card with bounded text, rate and
  TTL joins the screen rotation; see [the integration guide](../HOME_ASSISTANT.md)
  and `examples/home-assistant/weather-clock.yaml`.
- **GitHub updates from the Update page.** All / Stable / Beta filters, an explicit
  version picker, reinstall and downgrade with PIN confirmation, and a plain-language
  list of what a transition loses. The browser downloads the image and checks size,
  SHA-256 and the ESP-01S header; the clock only receives the verified upload and
  confirms its version after restart. Local-file upload remains available.
- **Settings page.** City search (Open-Meteo / GeoNames from your browser), reviewed
  JSON import, Saved only after a verified readback, private diagnostics export.
- **Robustness.** Weather response and parser memory are bounded; download age and
  source age are shown separately; upload finalization requires one complete
  authenticated request; a background tab catches up on its first status read.

## Install

- **From 1.11.0-beta.2 or newer:** open **Update**, keep _GitHub release_, choose
  **Stable**, select **v1.11.0 · Recommended**, show and enter the PIN, install.
  Reload the page after the restart.
- **From 1.10.0 or beta.1:** open `/update`, choose the downloaded
  `weather_clock-v1.11.0-<revision>.bin`, press **Show PIN on clock**, enter the six
  digits and upload. GitHub updates are available from then on.
- **From 1.9.x:** the old `/update` page asks for its own login/code; upload the
  same `.bin`. A new PIN is created on first boot and shown only on request.
- **First installation:** see the [installation guide](../INSTALLATION.md). The
  target is Generic ESP8266, **1 MB / 64 KB filesystem, DIO, 80 MHz**. One firmware
  file is all that is needed; the web interface is inside it.

Going back to 1.10.0 or beta.1 removes GitHub updating and the extra screens; keep
a local BIN to return. See [update compatibility](../UPDATES.md).

## Validation

Pinned build: **478,944 bytes** firmware, **288 bytes** below the mutual-OTA limit;
**38,480 bytes** static RAM; **62,007 / 65,536** instruction bytes including cache.
The embedded page is **67,158 bytes** before gzip, **20,685 bytes** in flash.

Passed: all seven host suites with ASan/UBSan (including the new language field,
its export/import and the fallback for an index from newer firmware); ESLint, Ruff
and asset reproducibility; release ordering and catalog tests; the dictionary test
(306 UI strings, complete it/de/fr dictionaries, placeholders preserved); the
Chromium regression over the actual embedded page at desktop and 320/390 px,
including switching en → it → de → fr → en and the English fallback when the
dictionary cannot be downloaded, with no browser storage used.

Hardware, 2026-11-03: a physical ESP-01S running beta.4 (6.9 days uptime) was updated
over the air with the PIN-authenticated upload, kept all settings and the PIN, and
was then switched to Italian, German and French from a real Chrome browser:
Settings, Clock and Update pages rendered translated, dates followed the locale,
the Update page listed the live GitHub catalog in German, and English was restored.
Older Stable rollback, power-loss recovery and a long soak on 1.11.0 are not yet
repeated for this build; the beta.4 rollback trial is documented in
[VALIDATION.md](../VALIDATION.md).
