# v1.11.0-beta.2 — GitHub updates with a PIN

Pre-release for ESP-01S. Physical OTA and long-running hardware validation remain pending.

The Update page can now check the project's Stable or Stable + Beta channel and
install a newer version without a manual file download. Read the release notes,
show the six-digit PIN on the clock, then press **Install & restart**.

Your browser downloads the image over HTTPS and verifies its hardware target,
size and SHA-256 before sending it to the clock. This also works when the clock's
page is opened over plain HTTP. The PIN is checked first, sent only to the clock,
and never stored. The browser tab must remain open during installation.

Beta selection is explicit and visible. A stable release supersedes an earlier
beta of the same version; no older/equal image is installed automatically. There
is no unattended update schedule. Local-file firmware and advanced filesystem
uploads remain available if GitHub is unreachable or a deliberate downgrade is
needed. Settings and PIN storage remain compatible.

The ESP does not acquire an HTTPS client, a GitHub token or a whole-image buffer.
Removing the unused stock updater page keeps this build within the existing OTA
budget. The compact HTTP adapter still uses the core's flash/image validation;
it withholds the last byte until the complete authenticated request, and rejects
empty, interrupted or multiple-file requests before committing.

Settings now reads non-restarting changes back before showing **Saved**. If the
values differ or verification fails, your edits remain available for retry.
The preset formerly named **Time & weather** is now **Combined clock + UV**;
the page explains that presets replace individual screen choices. Adjusting a
screen marks the preset **Custom**, and the Clock page explains unavailable options.

Code cleanup shares the HTTP JSON parser, moves a long constant out of RAM and
avoids repeated weather conversions and sun-label formatting. The resulting
image is 2,176 bytes smaller than the preceding local beta.2 build, with 368 bytes
less static RAM. Pinned lint/style tools and host sanitizers help check future
changes; no assembly or memory-budget increase was needed. See the
[optimization audit](../CODE_QUALITY.md).

## First installation

Use your installed firmware's existing file upload to install beta.2 once. After
that, online releases can be installed from its new Update page. Only the `.bin`
is needed; the web UI is included. The verified update catalog and images are
maintained by the [update-channel workflow](../UPDATES.md).

## Validation

- Pinned ESP-01S build: **476,496 bytes**; unchanged OTA budget 479,232 bytes.
- Static RAM: **38,464 bytes**; instruction region including cache: **62,007 / 65,536**.
- All seven host executables passed with ASan/UBSan; pinned ESLint/Ruff passed.
- Chromium checked the real embedded page, realistic-sized download/upload,
  stable/beta selection, invalid PIN, corrupt/oversized image, missing catalog,
  incompatible target, local upload fallback and desktop/mobile layout.
- Settings regressions cover a misleading successful save response, failed
  readback, retry, coordinate rounding and changes that reboot the clock.
- SHA-256 matches Node crypto at padding boundaries and maximum image size.
- Release staging checked real stable/beta assets, including a stable release
  retaining an older binary. Channel and metadata failure tests passed.

Physical OTA, reboot/recovery and a long-running hardware test remain unverified.
See [GitHub Actions](https://github.com/petrochen/esp8266-weather-clock-opensource/actions)
for build and channel-publication results. This build does not introduce automatic rollback.
